    What it checks

    • Upgradeability — EIP-1967 transparent / UUPS / beacon proxies, EIP-1822, legacy ZeppelinOS, Safe-style slot-0 proxies, EIP-1167 clones and EIP-7702 delegated wallets.
    • Who holds the keys — owner and proxy admin, classified as a single wallet (EOA), a Safe multisig (with threshold), a timelock (with delay), or renounced.
    • Privileged switches — mint, pause, blacklist / freeze / bot lists, owner-settable buy/sell tax, max-tx / max-wallet limits, trading on/off, seize / wipe, admin burn, fee exemptions.
    • Live state — whether paused() is true right now, token name / symbol / supply, code hash.
    • Source verification — exact / partial match on Sourcify.

    How it works & limits

    • Everything runs in your browser: it reads the contract with a few JSON-RPC calls (public node, your wallet's node, or your own RPC URL) and matches function selectors in the bytecode. No server, no account, no tracking.
    • If public nodes are blocked or rate-limited, switch the data source, or paste the bytecode for a fully offline check.
    • It is a heuristic, not an audit and not a buy/sell simulation. Custom function names can evade selector matching; a clean result is not a guarantee.

    它检查什么

    • 可升级性：EIP-1967 透明 / UUPS / Beacon 代理、EIP-1822、旧版 ZeppelinOS、Safe 式 slot-0 代理、EIP-1167 克隆、EIP-7702 委托钱包。
    • 钥匙在谁手里：owner 和代理管理员，分成单个钱包（EOA）、Safe 多签（含门槛）、时间锁（含延迟）、已放弃。
    • 特权开关：增发、暂停、黑名单/冻结/bot 名单、owner 可改的买卖税、单笔/单钱包限额、交易开关、没收/清零、管理员销毁、免税名单。
    • 实时状态：paused() 此刻是否为 true，代币名称/符号/总量，代码哈希。
    • 源码验证：Sourcify 完全/部分匹配。

    原理与局限

    • 全部在你的浏览器里运行：通过几次 JSON-RPC 调用读取合约（公共节点、你钱包的节点或你自己的 RPC），再在字节码里匹配函数选择器。没有服务器、不用注册、不追踪。
    • 如果公共节点被拦截或限流，可以换数据源，或者粘贴字节码做完全离线的检查。
    • 这是启发式检查，不是审计，也不是买卖模拟。自定义函数名可以绕过选择器匹配；结果干净不代表安全。
